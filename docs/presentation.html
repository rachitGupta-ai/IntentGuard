The Problem

India's Digital India is AI-operated — agents deploy and remediate without human oversight. Existing controls answer "is this identity allowed?" — never "was this intended?"

  • sudoers / SELinux / PAM / EDR: identity + permission, no semantic understanding
  • ₹19.5 crore avg. breach cost in India · AI agents run 40% of cloud ops

🤖 AI Agent Hijack

Prompt-injected agent runs authorized-but-unintended command

📋 Paste Payload

Valid syntax, malicious intent — clipboard-based attack

🕵️ Session Takeover

Correct identity, wrong human — behavioral drift undetected

Objective

  • Pre-execution semantic firewall for Linux
  • Score every command vs. declared intent + learned profile
  • ALLOW ASK BLOCK  in <2 seconds
  • Explained in 11 Indian languages
  • Zero data leaves the network
  • 705 passing tests · working system

Innovation & Novelty
C-DAC  |  MINISTRY OF ELECTRONICS AND INFORMATION TECHNOLOGY (MeitY), GOVERNMENT OF INDIA6 / 11

Four things no other team in this hackathon combines

1 · Novel Scoring Architecture

  • Renormalized weighted sum — composite is a convex combination, guaranteed [0,1]
  • 3 of 4 components fully deterministic; same inputs → same score, always
  • Graceful degradation: LLM unavailable → 3-component scoring still enforces
  • AgentRiskAdjuster: +25%/marker, monotonic, never lowers

2 · Sovereign AI (runtime-inspectable)

  • Qwen 2.5 14B on on-premise BT SRE server — no cloud dependency
  • GET /api/sovereignty → live: onPremise=true, dataLeavesNetwork=false
  • Provider-agnostic: one config line switches Ollama ⇄ Gemini

3 · Deep Explainability

  • GET /api/explain/{id} → ranked component contributions with notes
  • Verified: SEQUENCE_SURPRISE 1.0 ("surprise for token 'curl'"), SEMANTIC 1.0
  • Not a black-box score — every verdict is auditable and attributable

4 · 11 Indian Languages

  • TechnicalTokenProtector masks commands/paths/IPs before translation, restores byte-for-byte
  • Zero corruption of technical content across translations
  • Bhashini government-stack fallback · Hindi/Tamil/Bengali verified live

Security & Safety

Seven-layer defense-in-depth — each layer only raises restrictiveness, never lowers it

LayerNameWhat it doesVerdict
L1 ★Tamper ResistanceCommand targets engine → force score=1.0, BLOCK. Cannot be softened by any rule.BLOCK
L2Policy DENYAdmin-configured hard deny — runs before learning clamp, never downgradedBLOCK
L3Blast RadiusProtected targets, mass-ops (recursive/wildcards), destructive verbsBLOCK
L4Divergence Scoring4-component renormalized pipeline — AgentRiskAdjuster uplifts for AGENT risk markers→ score
L5Decision EngineThreshold map + Learning clamp (new users → ASK never BLOCK) + Agent containment→ action
L6Dual-ControlFour-eyes: distinct approver required · self-approval rejected · timeout → BLOCK→ floor
L7Monitoring WatchdogAlerts when audit feed goes silent (5s) — detects auditd disabled by attackerALERT

Key invariant: Contribution.raiseTo() pattern — short-circuit exits (L1–L3) bypass all later stages and cannot be softened.
